Remote Trebuchet

This was quite a fun project, the point was to try and learn a bit more about how to program android apps while still keeping a hardware element. I chose android, because I had opted to go to Durham to help the organisers of Durhack X coordinate coach travel (they’d had to book private coaches because the trains weren’t running that weekend), over doing my Mobile Device Programming coursework which almost certainly contributed to me being 2% off of a 2:1 at the end of my degree. But we move, and I had fun. Anyway, in the end I had python scripts that could recieve commands via web request and actuate the trebuchet, and an android app that would send a web request upon clicking a button. Unfortunately the android app didn’t compile because the device that I’d brought with me was running Android 4.4 on API 19, and, as it turns out, trying to find an IDE that will both compile for that and play well with gradle is a nightmare.
