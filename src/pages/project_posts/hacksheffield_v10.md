# Oliver Charles <span class="text-gradient">Hidden</span>
This was a pretty cool project which consisted of a unity game and a reciept printer. The idea is that there's stuff in the game that you can only see by taking pictures of it using the in game camera, but the photos are printed onto physical reciept paper for you to look at in real life. I was responsible for writing the server which allowed the game to communicate with the reciept printer.

You can read more below, but I do intend to write something more substantial here at some point.
