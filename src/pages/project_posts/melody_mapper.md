# Melody <span class="text-gradient">Mapper</span>
The idea behind this project was to create album art based on the music in the album. To do this we got a buggy that could draw and wrote some software that encoded each note as a different movement. I was responsible for the micropython code running on the buggy, which was controlled by a BBC Microbit.

You can read more below, but I do intend to write something more substantial here at some point.
