# Terra<span class="text-gradient">Space</span>
During the making of this project, I mainly learned about two things: how to implement custom domains for github pages sites, and how to make a repository run as a website through github pages. 

I also learned a bit about voxels and the maths for 3D terrain generation, but I don't think any of it went in.

The website is still up and running, but the custom domain (which was terraspace.design) has long since expired.
